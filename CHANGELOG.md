# Changelog

## 0.1.0 — 2026-09-15

First public alpha.

- Local Windows studio, prompt editor, and production settings.
- Official Codex sign-in, progress, scoped approvals, and persistent jobs.
- Saved-thread continuation and scene-checkpoint production contract.
- Blender/FFmpeg helpers, optional Kokoro speech, captions, and sound.
- Fixed local demo, previews, editable outputs, and export checks.
- Windows setup, release packaging, tests, documentation, and issue templates.

Known limits: Windows-first single-user operation; variable generated quality; long-form duration targets require suitable hardware, tools, time, and Codex usage. No unattended scheduler or automatic social publishing.
