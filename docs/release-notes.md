# v0.1.0 — First public alpha

A local Windows studio for creating editable animated stories with Codex and free production tools.

## Included

- Prompt settings, official Codex sign-in, progress updates, and action approvals.
- Saved project history, thread continuation, and checkpoint-oriented production.
- A workflow for scripts, reusable characters, voices, scenes, audio, captions, and credits.
- Blender/FFmpeg helpers, optional local speech, a fixed demo, and MP4 previews.
- Windows setup launchers, technical export checks, tests, and public documentation.

Download the Windows ZIP, extract it into Downloads, and double-click **Start Studio.cmd**. Setup guides you through missing Python/Codex prerequisites. Media software and models are separate downloads. [Quick start](https://github.com/abkmystery/prompt-video-studio/blob/main/docs/quickstart.md)

## Expectations

This is an alpha for local, single-user use. Start with a 30-second draft. Output quality varies and needs human review.

Durations up to 20 minutes are targets, not verified quality or completion guarantees. Long work can take hours and multiple sessions. Codex usage is separate from the free local tools. The sample demo is a fixed template.

The release excludes credentials, private films, runtime session data, logs, virtual environments, downloaded tools, and model weights. Application code is MIT; third-party components keep their own licenses.
