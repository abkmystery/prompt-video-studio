# v0.2.0 — Assets and continuations

This alpha adds reusable asset creation and source-based continuation workflows to the local Windows studio.

## Included

- Create reusable character, object, and scene assets, use them in films, and derive immutable new versions without overwriting originals.
- Extend completed or imported videos, or revise from completed videos, imported videos, and plain UTF-8 scripts. Each continuation is a new job with copied source material and lineage.
- Import MP4, WebM, or MOV video up to 512 MiB and TXT, MD, or SRT scripts up to 1 MiB through validated local storage.
- Choose manual action approval or automatic Codex safety review per job. Automatic review retains the same scoped writable folders, network access subject to approval, and application output checks.
- Updated film, asset, continuation, library, progress, download, and approval interfaces.
- Continued Blender/FFmpeg production, optional local speech, fixed demo, resume support, and technical export validation.

Download the Windows ZIP, extract it into Downloads, and double-click **Start Studio.cmd**. Setup guides you through missing Python/Codex prerequisites. Media software and models are separate downloads. [Quick start](https://github.com/abkmystery/prompt-video-studio/blob/main/docs/quickstart.md)

## Expectations

This remains a Windows-first alpha for local, single-user use. Start with a short draft. Generated films and assets vary in quality and need human review before reuse or publication.

Durations up to 20 minutes are targets, not quality or completion guarantees. Long work can take hours and multiple sessions. Automatic safety review does not grant unrestricted computer access or guarantee that every requested action will be approved. Codex usage is separate from the free local tools, and the sample demo remains a fixed template.

The release excludes credentials, private films, runtime session data, logs, virtual environments, downloaded tools, and model weights. Application code is MIT; third-party components keep their own licenses.
